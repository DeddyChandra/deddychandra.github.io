Welcome to the new portfolio (and how I rebuilt it)

This site used to be a generic Bootstrap CV template with a "Web Developer, Gamers, Buddhist" tagline and a tab full of school-farewell photos. It was time.

The new version is built around a single idea: show the work, not the title. Every section now leads with what I shipped and what it changed — revenue numbers, latency drops, ops time saved.

What's under the hood

It's intentionally simple — vanilla HTML, a single CSS file, three small JS modules:

  • theme.js — dark/light toggle that respects system preference
  • i18n.js — a tiny translation engine swapping data-i18n attributes (EN / 中文 / Bahasa)
  • main.js — scroll reveals, nav state, mobile menu

No build step, no framework. I can edit any file and just refresh. That matters more to me than a fancy stack.

What's next

I'll be filling in the case-study screenshots (Datadog APM, the insurance flow, loan creation) and writing a few deeper posts on database performance, event-driven systems, and DevSecOps. Subscribe via RSS — or just drop me an email.

The goal isn't a perfect portfolio. It's one that respects the reader's time.
